Writing your own nodes

Navisworks: Markup

6 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Markup.AddCloud

EXPERIMENTAL: draws a revision-cloud redline through the given markup-space points (undocumented Navisworks API). Accepts [x,y] pairs or a flat x1,y1,x2,y2,… list.

InputTypeDefaultWhat it does
viewpoint requiredany—The saved viewpoint (or its name).
points requiredany[]—Cloud outline: a list of [x, y] pairs, or a flat list x1, y1, x2, y2, … (3+ points).
coloranynullLine colour: a Color, hex "#RRGGBB" or [r,g,b] (empty keeps the Navisworks default).
thicknessinteger2Line thickness in pixels.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
viewpointSavedViewpointThe stored viewpoint (pass-through for chaining).

markup redline cloud revision revcloud viewpoint

Markup.AddNumberTag

EXPERIMENTAL: draws a circled number on a saved viewpoint and optionally attaches a comment — a tag substitute (real Find-Tags tags have no public API). Markup-space coordinates; calibrate with Markup.List.

InputTypeDefaultWhat it does
viewpoint requiredany—The saved viewpoint (or its name).
number requiredinteger—The tag number to draw.
x requirednumber—Markup-space X of the tag centre.
y requirednumber—Markup-space Y of the tag centre.
radiusnumber0.08Circle radius in markup-space units.
commentstring""Optional comment attached to the viewpoint (shows in the Comments panel).
coloranynullLine colour: a Color, hex "#RRGGBB" or [r,g,b] (empty keeps the Navisworks default).
thicknessinteger2Line thickness in pixels.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
viewpointSavedViewpointThe stored viewpoint (pass-through for chaining).

markup redline tag number bubble comment viewpoint

Markup.AddShape

EXPERIMENTAL: draws a line, arrow or ellipse redline on a saved viewpoint (undocumented Navisworks API). Markup-space coordinates; calibrate with Markup.List.

InputTypeDefaultWhat it does
viewpoint requiredany—The saved viewpoint (or its name).
shape requiredstring—line, arrow (points from start to end) or ellipse (fitted to the corner-to-corner box).
x1 requirednumber—Markup-space X of the start point (tail, or first box corner).
y1 requirednumber—Markup-space Y of the start point.
x2 requirednumber—Markup-space X of the end point (head, or opposite box corner).
y2 requirednumber—Markup-space Y of the end point.
coloranynullLine colour: a Color, hex "#RRGGBB" or [r,g,b] (empty keeps the Navisworks default).
thicknessinteger2Line thickness in pixels.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
viewpointSavedViewpointThe stored viewpoint (pass-through for chaining).

markup redline line arrow ellipse circle shape draw viewpoint

Markup.AddText

EXPERIMENTAL: draws a text redline on a saved viewpoint (undocumented Navisworks API). Coordinates are markup space — (0,0) is the view centre; calibrate with Markup.List.

InputTypeDefaultWhat it does
viewpoint requiredany—The saved viewpoint (or its name).
text requiredstring—The text to draw.
x requirednumber—Markup-space X of the text anchor (0 = view centre).
y requirednumber—Markup-space Y of the text anchor (0 = view centre).
coloranynullLine colour: a Color, hex "#RRGGBB" or [r,g,b] (empty keeps the Navisworks default).
thicknessinteger2Line thickness in pixels.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
viewpointSavedViewpointThe stored viewpoint (pass-through for chaining).

markup redline text annotate label viewpoint tag

Markup.List

EXPERIMENTAL: lists the redline markups on a saved viewpoint — types, texts and anchor positions. Draw one markup by hand and read it here to learn the coordinate scale for the Add nodes.

InputTypeDefaultWhat it does
viewpoint requiredany—The saved viewpoint (or its name).
documentDocumentnullThe document (defaults to the active document).
OutputType
countinteger
typesstring[]
textsstring[]
positionsany

Returns: Markup count, per-markup type names, texts (empty for shapes) and anchor positions as [x, y] — the calibration reference for the Add nodes.
