Writing your own nodes

Navisworks: Grids

3 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Grids.ClosestIntersection

The grid intersection and level nearest to any point — ready-made "B-3 : Level 2" location labels for clash naming, reports and zone tagging. Document units.

InputTypeDefaultWhat it does
point requiredany—The query point (document units) — e.g. a ClashResult center or a bounding-box center.
documentDocumentnullThe document (defaults to the active document).
OutputType
namestring
positionPoint
levelNamestring
labelstring

Returns: The intersection name (e.g. "B-3"), its position, the level name, and a combined "B-3 : Level 2" label.

grid intersection closest nearest location label level

Grids.Intersections

All grid intersections of the active grid system, per level — names like "A-1" with positions in document units. The API only answers closest-intersection queries, so intersections are discovered by sampling the model's bounding box and completing the line lattice; raise samples if a very dense grid comes back incomplete.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
samplesinteger20Sampling density per axis used to seed the discovery (higher finds denser grids; 2-100).
OutputType
namesstring[]
pointsPoint[]
levelNamesstring[]

Returns: Intersection names (e.g. "A-1"), their positions (document units) and the level each lies on.

grid intersection intersections gridline axis lattice

Grids.Levels

The model's own levels from the active grid system — names and elevations (document units) without hand-typed elevation lists. Grid data comes from source models (e.g. Revit/IFC) and is read-only.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputType
namesstring[]
elevationsnumber[]
levelsdict[]

Returns: Level names, their elevations (document units) and the GridLevel objects, in grid-system order.

grid level levels elevation storey story floor
