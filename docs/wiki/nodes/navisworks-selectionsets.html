For developers

Writing your own nodes

Navisworks: SelectionSets

13 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

SelectionSet.ByName

Finds a saved selection or search set by its display name (searches folders too).

InputTypeDefaultWhat it does
name requiredstring—The set's display name.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetSelectionSetThe stored selection set.

selection set byname find

SelectionSet.Create

Creates a saved selection set from the given items. An existing top-level set with the same name is replaced.

InputTypeDefaultWhat it does
name requiredstring—Display name for the new set.
items any number of wires requiredModelItem[]—The model items to store.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetSelectionSetThe stored selection set.

selection set create save new

SelectionSet.CreateFromSearch

Creates a live SEARCH set from a property-equals rule — it re-evaluates as the model changes. An existing top-level set with the same name is replaced.

InputTypeDefaultWhat it does
name requiredstring—Display name for the new search set.
categoryName requiredstring—Category display name (e.g. "Element"). Internal names do not match.
propertyName requiredstring—Property display name (e.g. "Level"). Internal names do not match.
value requiredany—The value to match (string, number, boolean or date).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetSelectionSetThe stored search set (it re-evaluates as the model changes).

selection search set create live rule

SelectionSet.Delete

Deletes a saved selection or search set by name (searches folders too). Returns false when absent — safe for clean re-runs.

InputTypeDefaultWhat it does
name requiredstring—The set's display name (folders are searched too).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
deletedbooleanTrue when a set was deleted; false when no set has that name.

selection set delete remove clean

SelectionSet.Duplicate

Duplicates a saved selection or search set in its folder (a search set stays a live search); the copy is named "<name> copy" unless newName is given. Running it again adds another copy.

InputTypeDefaultWhat it does
selectionSet requiredSelectionSet—The set to copy.
newNamestring""Name for the copy (empty uses "<name> copy").
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetSelectionSetThe new stored set.

selection set duplicate copy clone backup

SelectionSet.Info

What a saved set is: its name, whether it is a fixed "selection" or a live "search" set, how many items it selects right now (a search set is evaluated once to count) and its folder path ("" at the top level).

InputTypeDefaultWhat it does
selectionSet requiredSelectionSet—The selection or search set.
documentDocumentnullThe document (defaults to the active document).
OutputType
namestring
kindstring
itemCountinteger
folderstring

Returns: The set's name, its kind ("selection" or "search"), how many items it selects and its folder path.

selection set info kind count size folder search set audit

SelectionSet.Items

The model items a saved set selects. Search sets are re-evaluated against the model.

InputTypeDefaultWhat it does
selectionSet requiredSelectionSet—The selection or search set.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The items the set currently selects (search sets are evaluated).

selection set items contents resolve

SelectionSet.MoveToFolder

Moves a saved selection or search set into a folder (appended at the end). A set already in the folder is left alone, so re-runs are clean.

InputTypeDefaultWhat it does
selectionSet requiredany—The set, or its display name.
folder requiredany—The target folder (e.g. from SelectionSets.CreateFolder), or its name.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetSelectionSetThe moved stored set (pass-through for chaining).

selection set move folder organize

SelectionSet.Name

The display name of a saved selection or search set.

InputTypeDefaultWhat it does
selectionSet requiredSelectionSet—The selection or search set.
OutputTypeWhat it gives
namestringThe set's display name.

selection set name displayname

SelectionSet.Rename

Renames a saved selection or search set (accepts the set or its current name; searches folders too). Batch-rename via lacing.

InputTypeDefaultWhat it does
selectionSet requiredany—The set, or its current display name.
newName requiredstring—The new display name.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetSelectionSetThe renamed stored set (pass-through for chaining).

selection set rename name batch

SelectionSets.All

All saved selection and search sets in a document, including those inside folders.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
selectionSetsSelectionSet[]Every set, including those nested in folders.

selection sets saved search all

SelectionSets.BulkByPropertyValues

One search set per distinct value of a property (e.g. one set per Level) — bulk set generation without the Find Items dialog. Existing same-named sets in the target location are replaced.

InputTypeDefaultWhat it does
categoryName requiredstring—Category display name (e.g. "Element"). Internal names do not match.
propertyName requiredstring—Property display name (e.g. "Level"). Internal names do not match.
folderNamestringnullFolder to file the sets under (null/empty stores them at the top level).
documentDocumentnullThe document (defaults to the active document).
OutputType
selectionSetsModelItemCollection[]
valuesany

Returns: The stored sets and the distinct values, index-aligned.

selection sets bulk generate values level system

SelectionSets.CreateFolder

Creates a folder in the Sets window, optionally nested under a parent folder. An existing same-named folder in that location is reused, so re-runs are clean.

InputTypeDefaultWhat it does
name requiredstring—The folder's display name.
parentFolderFolderItemnullParent folder for nesting (null creates at the top level).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
folderFolderItemThe stored folder (an existing same-named folder in that location is reused).

selection sets folder create organize nested
