Writing your own nodes

Navisworks: Properties

13 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Properties.AsDictionary

Every property of an item flattened to a "Category.Property" → value dictionary (full data dump).

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
OutputTypeWhat it gives
propertiesdictA "Category.Property" → value dictionary (full data dump / JSON export).

property dictionary all dump json export

Properties.Categories

The property category names available on a model item.

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
OutputTypeWhat it gives
categoriesstring[]The category display names.

property categories tabs groups

Properties.CustomTabs

The user-defined property tabs on an item (discovery/QA before SetCustom or RemoveCustomTab). Built-in source-file categories are not listed — use Properties.Categories for those.

InputTypeDefaultWhat it does
modelItem requiredModelItem—The model item to inspect.
OutputTypeWhat it gives
tabNamesstring[]The user-defined tab display names, in tab order.

property custom tabs list user discover

Properties.Discover

Lists every property the given items carry, one row per category and property with how many items have it (Items), how many different values it holds (Distinct, counted up to 10000) and the first few values (Samples) — the answer to "what data does this model actually have?". Reads every property of every item once, so cost grows with items times properties.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to look at (their own properties only, not their children's).
maxSamplesinteger3How many distinct sample values to show per property (0 to 50).
OutputTypeWhat it gives
tableDyncameloTableA table with the columns Category, Property, Items, Distinct and Samples.

properties discover explore schema catalog what data categories values profile audit inventory

Properties.HasProperty

True when the item carries the property — drives model-QA missing-data masks.

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
categoryName requiredstring—Category display name; internal names also match.
propertyName requiredstring—Property display name; internal names also match.
OutputTypeWhat it gives
hasPropertybooleanTrue when the property exists on the item — drives model-QA "missing data" masks.

property has exists qa missing

Properties.InCategory

All property names and values inside one category of an item. Returns empty lists when the item lacks the category.

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
categoryName requiredstring—Category display name (e.g. "Element"); internal names also match.
OutputType
namesstring[]
valuesany

Returns: Index-aligned property names and plain values (empty lists when the category is absent).

property category all names values tab

Properties.RemoveCustomTab

Removes a user-defined property tab from items. Items without the tab are skipped (see removedCount) — safe for clean re-runs of SetCustom graphs.

InputTypeDefaultWhat it does
modelItems any number of wires requiredModelItem[]—The model items to clean.
tabName requiredstring—The tab's user-visible name.
OutputType
modelItemsModelItem[]
removedCountinteger

Returns: The items (pass-through) and how many items actually had the tab.

property custom remove delete tab clean user

Properties.RenameCustomTab

Renames a user-defined property tab in place (same properties, same internal name — search sets targeting the tab stay valid). Items without the tab are skipped.

InputTypeDefaultWhat it does
modelItems any number of wires requiredModelItem[]—The model items whose tab to rename.
tabName requiredstring—The tab's current user-visible name.
newTabName requiredstring—The new user-visible name.
OutputTypeWhat it gives
modelItemsModelItem[]The items (pass-through for chaining).

property custom rename tab user

Properties.SetCustom

Writes a user-defined property tab onto items — values are searchable, schedulable, and travel with the NWF/NWD (source files are never modified). Merge keeps existing same-tab properties; new values win on name collisions.

InputTypeDefaultWhat it does
modelItems any number of wires requiredModelItem[]—The model items to stamp.
names requiredstring[]—Property display names (index-aligned with values).
values requiredany[]—Property values (string, number, boolean or date; index-aligned with names).
tabNamestring"Dyncamelo Data"User-visible tab name; a stable internal name is derived from it so search sets can target the tab.
mergebooleantrueTrue keeps existing properties of a same-named tab (new values win on name collisions); false replaces the tab's content entirely.
OutputTypeWhat it gives
modelItemsModelItem[]The items (pass-through for chaining).

property custom set write user tab parameter smartproperties stamp

Properties.ToTable

Reads the named properties of every item into a table with one row per item and one column per name ("Element.Category", "Item|Layer", a bare property name, or @Name, @Path, @Guid), ready for the Table nodes, Excel or CSV; a property an item lacks is an empty cell. Reads items times names values.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items, one table row each.
properties requiredany[]—The columns: "Category.Property" or "Category|Property" (split at the first "|" if there is one, otherwise at the first "."), a bare property name (searched in every category, first match wins), or @Name, @Path, @Guid.
OutputTypeWhat it gives
tableDyncameloTableA table with one column per entry of properties, headed with the text as written.

properties table export rows columns excel csv dataframe report schedule quantities

Properties.Value

Reads a property value from a model item, converted to a plain value. Returns null when the property is absent.

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
categoryName requiredstring—Category display name (e.g. "Element", "Item"); internal names also match.
propertyName requiredstring—Property display name (e.g. "Category", "Name"); internal names also match.
OutputTypeWhat it gives
valueanyThe property value as a plain .NET value, or null when the item lacks the property.

property value parameter attribute data

Properties.ValueAsString

Reads a property value as text. Returns "" when the property is absent.

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
categoryName requiredstring—Category display name; internal names also match.
propertyName requiredstring—Property display name; internal names also match.
OutputTypeWhat it gives
textstringThe value as text ("" when the property is absent).

property value string text display
