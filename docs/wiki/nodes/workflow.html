For developers

Writing your own nodes

Workflow

16 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Flow.Then

Passes a value through unchanged AFTER the wired 'after' nodes have run — makes the execution order of side-effect nodes explicit (e.g. set a section box, THEN save the viewpoint).

InputTypeDefaultWhat it does
value requiredany—The value to pass through unchanged.
after requiredany—Wire any output of the node that must run first (its value is ignored).
after2anynullOptional second node that must run first.
after3anynullOptional third node that must run first.
OutputTypeWhat it gives
valueanyThe value input, unchanged.

sequence order passthrough wait after chain depend

Flow.Try

Carries on after a failure: gives the node's result, or your fallback plus the error text when that node failed — nothing after it turns red.

InputTypeDefaultWhat it does
value requiredany—The node output to try. Wire the node that might fail.
fallbackanynullWhat to output when it failed (nothing by default).
OutputType
resultany
failedboolean
errorstring

Returns: The "result" (the value, or the fallback after a failure), whether it "failed", and the "error" text.

try catch error recover fallback optional safe exception on error

Flow.Wait

Waits the given number of seconds, then passes the value through unchanged - use it to pause between steps of a workflow.

InputTypeDefaultWhat it does
value requiredany—The value to pass through after the pause (it is also what makes the pause happen in the right place).
secondsnumber1How long to wait, 0 to 3600 seconds (fractions allowed).
OutputTypeWhat it gives
valueanyThe value input, unchanged.

wait sleep pause delay timer throttle seconds

Flow.When

Runs the nodes wired after it only when the condition is true; when false they are skipped (idle, not an error) — e.g. export only if there are clashes.

InputTypeDefaultWhat it does
value requiredany—The value to pass on when the condition is true. Wire the output of the node that must have run.
condition requiredboolean—True lets the branch run; false skips everything wired after this node.
OutputTypeWhat it gives
valueanyThe value input, or nothing when the condition is false.

if only skip branch gate conditional run if guard

Loop.Collect

Interactive node: it has its own controls on the canvas.

Closes a loop and collects one value per iteration. Wire Loop.Item's 'loop' output into 'loop' and the per-item value into 'value'; 'results' is the list of collected values, available after the loop. Downstream of 'results' runs once.

InputTypeDefaultWhat it does
loop requiredany—Loop handle from Loop.Item.
value requiredany—The value to collect this iteration.
OutputTypeWhat it gives
resultsany[]One collected value per item.

Loop.Item

Interactive node: it has its own controls on the canvas.

Yields the current item of a loop. Wire a list into 'items', wire 'item' into the nodes that should run per item, and wire 'loop' into a Loop.Collect to close the loop. The engine runs everything between here and Loop.Collect once per item, in order.

InputTypeDefaultWhat it does
items requiredany[]—The list to iterate.
OutputTypeWhat it gives
itemanyThe current item (per iteration).
indexintegerThe current 0-based index.
countintegerThe total number of items.
loopanyLoop handle — wire into Loop.Collect to close the loop.

Workflow.ForEach

Runs a sequence of actions on each item, one item fully before the next — the per-item ordered loop (zoom → isolate → save viewpoint → next) that wiring and lacing cannot express. Wire items and a List.Create of Action.* nodes.

InputTypeDefaultWhat it does
items requiredany[]—The items to iterate. Each element becomes the current item for one pass; an element may itself be a group (a sub-list).
actions requiredany[]—The actions to run per item, in order — build this with List.Create from Action.* builder nodes.
OutputTypeWhat it gives
resultsany[]One entry per item: the value that item's actions collected (unwrapped when a single value, a list when several, the item itself when none). For a per-item Save Viewpoint workflow this is the list of created viewpoints.

workflow foreach for each loop iterate sequence per item batch each

Actions

Action.Ghost

Per item: applies a TEMPORARY transparency to the given items (wire the whole found set) so the highlighted item reads against a faded context. Captured per viewpoint. Put before Action.Highlight; reset each item with Action.ResetTemporaryAppearance.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The items to fade each iteration (usually the whole found set — the current item is made solid again by Action.Highlight).
transparencynumber0.850 = opaque, 1 = invisible (0.85 fades to a faint context).
OutputTypeWhat it gives
actionIWorkflowActionA ghost action for Workflow.ForEach.

action ghost fade transparency temporary workflow foreach context

Action.Highlight

Per item: applies a TEMPORARY color to the current item so it stands out — captured per viewpoint by Action.SaveViewpoint, so each view keeps its own highlight. Pair with Action.Ghost to fade the rest.

InputTypeDefaultWhat it does
color requiredany—A Color, a "#RRGGBB" string, or a list of three numbers.
transparencynumber0.0Transparency for the highlighted item (0 = solid, so it stands out of the ghosted rest).
OutputTypeWhat it gives
actionIWorkflowActionA highlight action for Workflow.ForEach.

action highlight color temporary workflow foreach spotlight

Action.Isolate

Per item: shows the current item and hides everything else (Appearance.Isolate). Place before Save Viewpoint to bake the isolation into each view.

No inputs.

OutputTypeWhat it gives
actionIWorkflowActionAn isolate action for Workflow.ForEach.

action isolate workflow foreach only focus

Action.OverrideColor

Per item: overrides the current item's color (Appearance.OverrideColor).

InputTypeDefaultWhat it does
color requiredany—A Color, a "#RRGGBB" string, or a list of three numbers.
OutputTypeWhat it gives
actionIWorkflowActionA recolor action for Workflow.ForEach.

action color override workflow foreach paint tint

Action.ResetAppearance

Per item: removes color and transparency overrides from the current item (Appearance.Reset).

No inputs.

OutputTypeWhat it gives
actionIWorkflowActionA reset-appearance action for Workflow.ForEach.

action reset appearance workflow foreach restore original

Action.ResetTemporaryAppearance

Per item: clears all TEMPORARY color/transparency overrides (Appearance.ResetTemporary) — put first in the sequence so the previous item's highlight/ghost doesn't linger into this view.

No inputs.

OutputTypeWhat it gives
actionIWorkflowActionA reset-temporary-appearance action for Workflow.ForEach.

action reset temporary appearance workflow foreach clear clean

Action.SaveViewpoint

Per item: saves the current view as a saved viewpoint named from the item. With bakeOverrides on, the current isolation AND temporary color/transparency are stored in the view, so recalling it restores that exact look. Collected as the loop's per-item result.

InputTypeDefaultWhat it does
namestring"{name}"Viewpoint name; supports {name}, {index1}, {count} templating (default {name} = the item's name).
folderstring"Dyncamelo Views"Viewpoint folder to file them under (null/empty stores at the top level).
bakeOverridesbooleantrueTrue to capture the current hidden AND temporary color/transparency overrides into the viewpoint, so recalling it restores that exact isolation and highlighting.
OutputTypeWhat it gives
actionIWorkflowActionA save-viewpoint action that collects the created viewpoint.

action viewpoint view save workflow foreach capture snapshot

Action.ShowAll

Per item: un-hides every item in the model (Appearance.ShowAll) — a reset step, e.g. before re-isolating.

No inputs.

OutputTypeWhat it gives
actionIWorkflowActionA show-all action for Workflow.ForEach.

action showall workflow foreach reveal reset unhide

Action.ZoomTo

Per item: frames the current item in the view (Camera.ZoomToItems). Place before Save Viewpoint so each view is centred on its item.

InputTypeDefaultWhat it does
paddingFactornumber1.5Space to leave around the item (1 = tight fit).
OutputTypeWhat it gives
actionIWorkflowActionA zoom action for Workflow.ForEach.

action zoom workflow foreach frame fit focus
