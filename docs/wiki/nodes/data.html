For developers

Writing your own nodes

Data

4 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

JSON.Parse

Parses a JSON string into dictionaries, lists and values.

InputTypeDefaultWhat it does
json requiredstring—The JSON text to parse.
OutputTypeWhat it gives
valueanyThe parsed value (dictionary, list, number, string, boolean or null).

json deserialize decode

JSON.Stringify

Serializes any value to a JSON string.

InputTypeDefaultWhat it does
value requiredany—The value to serialize.
indentedbooleantrueTrue (default) for pretty-printed output.
OutputTypeWhat it gives
jsonstringThe JSON text.

json serialize encode tostring

Snapshot.Diff

Diffs two GUID-keyed dictionaries: added/removed/changed keys (values compared by JSON equality; nested dictionary key order is ignored).

InputTypeDefaultWhat it does
oldValue requiredIDictionary—The older snapshot dictionary.
newValue requiredIDictionary—The newer snapshot dictionary.
OutputType
addedKeysstring[]
removedKeysstring[]
changedKeysstring[]

Returns: Dictionary with "addedKeys", "removedKeys" and "changedKeys".

compare delta difference version changes model compare

XML.Parse

Parses XML into dictionaries, lists and strings (attributes as "@name", repeated elements as lists, mixed text as "#text").

InputTypeDefaultWhat it does
xml requiredstring—The XML text to parse.
OutputTypeWhat it gives
valueanyThe parsed value (dictionary of dictionaries/lists/strings).

xml parse deserialize decode markup schedule msp p6
