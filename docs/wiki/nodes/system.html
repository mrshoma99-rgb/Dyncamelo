Writing your own nodes

System

5 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

System.Environment

Reports the Windows user, computer name, operating system and the current, temp, Documents and AppData folders.

No inputs.

OutputType
userNamestring
machineNamestring
osVersionstring
currentDirectoryfile
tempPathfile
documentsPathfile
appDataPathfile

Returns: Dictionary with "userName", "machineName", "osVersion", "currentDirectory", "tempPath", "documentsPath" and "appDataPath".

user username machine computer os windows temp documents appdata folder whoami

System.OpenPath

Opens a file or folder with its default application, or shows it selected in Explorer when reveal is true.

InputTypeDefaultWhat it does
path requiredstring—The file or folder to open.
revealbooleanfalseTrue to show the item in Explorer (Windows) / open its containing folder (other systems) instead of opening it.
OutputTypeWhat it gives
pathstringThe path that was opened, for sequencing further nodes.

open explorer reveal show launch folder default app finder

System.Run

Runs a program with arguments, waits for it (stopped after the timeout) and returns its exit code, output and error text.

InputTypeDefaultWhat it does
executable requiredstring—The program to start: a full path, or a name found on the PATH.
argumentsstring""The command-line arguments as one string.
workingDirectorystring""The folder to run in; empty uses the current folder.
timeoutSecondsinteger60How long to wait before stopping the program (1 to 3600 seconds).
OutputType
exitCodeinteger
outputstring
errorstring

Returns: Dictionary with "exitCode", "output" (standard output) and "error" (standard error).

run execute process command exe cmd shell script launch

Web.Get

Downloads text from an http(s) address with GET; an error status such as 404 is returned (ok = false), only a network failure or timeout is an error.

InputTypeDefaultWhat it does
url requiredstring—The address, starting with http:// or https://.
headersIDictionarynullOptional request headers (name to value), e.g. an Authorization token.
timeoutSecondsinteger30How long to wait for the answer (1 to 600 seconds).
OutputType
statusinteger
bodystring
okboolean

Returns: Dictionary with "status" (HTTP code), "body" (response text) and "ok" (true for 2xx).

http https request download api rest url fetch json web

Web.Post

Sends data to an http(s) address with POST (JSON by default, e.g. a Teams or Slack web hook); an error status is returned (ok = false), only a network failure or timeout is an error.

InputTypeDefaultWhat it does
url requiredstring—The address, starting with http:// or https://.
body requiredany—The data to send: text as it is; anything else becomes JSON when the content type contains "json". Nothing wired sends an empty body.
contentTypestring"application/json"The Content-Type of the body; defaults to application/json.
headersIDictionarynullOptional request headers (name to value), e.g. an Authorization token.
timeoutSecondsinteger30How long to wait for the answer (1 to 600 seconds).
OutputType
statusinteger
bodystring
okboolean

Returns: Dictionary with "status" (HTTP code), "body" (response text) and "ok" (true for 2xx).

http https post send webhook teams slack api rest json notify upload
