Writing your own nodes

Navisworks: Transform

7 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

ModelItem.GetTransform

Reads an item's current (active) transform: origin = its translation (a practical base point), matrix = 16 numbers row-major (feed ModelItem.SetTransform to round-trip), hasOverride = whether a permanent transform override is applied.

InputTypeDefaultWhat it does
item requiredModelItem—The model item.
OutputType
originPoint
matrixnumber[]
hasOverrideboolean

Returns: The transform origin (translation — a practical base point), the 16-number row-major matrix, and whether a permanent override is active.

item transform get read matrix origin override position

ModelItem.MoveTo

Moves model items so the centre of their combined bounding box lands on a target point — place a group by where it should be, not by how far to push it. A permanent override: undoable, saved in the NWF, removed by ModelItem.ResetTransform. Re-running with the same target is a no-op once the items are there.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to move (they keep their layout relative to each other).
target requiredany—Where the centre of the items' combined bounding box should end up (a Point or a list of three numbers), in document units.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The moved items (pass-through for chaining).

item move moveto place position target centre center transform

ModelItem.ResetTransform

Removes permanent transform overrides, restoring items to their original position. To reset every override in the whole document, set resetAll to true — an unwired or empty items input alone does nothing (and errors) so an empty upstream filter can never wipe all placement work.

InputTypeDefaultWhat it does
itemsModelItem[]nullThe model items to reset.
resetAllbooleanfalseTrue to reset EVERY transform override in the document (items may then be left unwired). Explicit opt-in — an unwired or empty items list alone never wipes the whole document.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The reset items (empty when every override was reset via resetAll).

item transform reset restore original undo position

ModelItem.RotateAboutAxis

Rotates model items by an angle (degrees) about an axis through a point. A permanent override: undoable, saved in the NWF, removed by ModelItem.ResetTransform. Re-runs accumulate.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to rotate.
origin requiredany—A point on the rotation axis (document units): a Point or a list of three numbers.
axis requiredany—The axis direction (need not be unit length): a Vector or a list of three numbers.
degrees requirednumber—The rotation angle in degrees (right-hand rule around the axis).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The rotated items (pass-through for chaining).

item rotate rotation axis angle degrees transform

ModelItem.Scale

Scales model items uniformly about a point — default: the centre of the items' combined bounding box, so the group grows or shrinks in place and keeps its internal layout. A permanent override: undoable, saved in the NWF, removed by ModelItem.ResetTransform. Re-runs accumulate (each run scales again). One override per item, so allow a moment on large selections.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to scale. Wire the items themselves, not a container AND its children.
factor requirednumber—The scale factor: 2 doubles the size, 0.5 halves it, 1 changes nothing. Must be positive.
aboutanynullThe fixed point of the scaling (a Point or a list of three numbers); leave unwired to scale about the centre of the items' combined bounding box.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The scaled items (pass-through for chaining).

item scale resize size grow shrink factor transform units

ModelItem.SetTransform

Sets the permanent transform override of model items to an absolute 4×4 matrix (16 numbers, row-major, translation at indices 3/7/11) — mirror-place or scale-in-place for power users. Unlike Translate/RotateAboutAxis this REPLACES any earlier override; re-runs are idempotent.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to transform.
matrix requiredany—16 numbers, row-major (translation at indices 3, 7, 11; bottom row 0 0 0 1), or four rows of four numbers, or a matrix from ModelItem.GetTransform.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The transformed items (pass-through for chaining).

item transform matrix set override scale mirror

ModelItem.Translate

Moves model items by a vector, in document units (chain Units.Convert for meters/feet). A permanent override: undoable, saved in the NWF, removed by ModelItem.ResetTransform. Re-runs accumulate — each run moves the items again.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to move.
vector requiredany—The offset, in document units: a Vector (Vector.ByCoordinates) or a list of three numbers.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The moved items (pass-through for chaining).

item translate move offset transform shift
