For developers

Writing your own nodes

Color

18 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Color Picker

Interactive node: it has its own controls on the canvas.

A color chosen with a picker.

No inputs.

OutputTypeWhat it gives
colorColorThe chosen color.

Color.ByARGB

Creates a color from alpha, red, green and blue values (0-255).

InputTypeDefaultWhat it does
ainteger255Alpha channel, 0–255 (default fully opaque).
rinteger0Red channel, 0–255.
ginteger0Green channel, 0–255.
binteger0Blue channel, 0–255.
OutputTypeWhat it gives
colorColorThe color.

rgb argb rgba

Color.ByHSV

Creates a color from hue (degrees, wraps around), saturation and value (0-1, clamped).

InputTypeDefaultWhat it does
hue requirednumber—Hue in degrees (0 = red, 120 = green, 240 = blue); wraps around.
saturation requirednumber—Saturation, 0 (grey) to 1 (vivid); clamped.
value requirednumber—Value (brightness), 0 (black) to 1 (full); clamped.
alphainteger255Alpha channel, 0–255 (default fully opaque).
OutputTypeWhat it gives
colorColorThe color.

hsv hsb hue saturation brightness create

Color.ByValues

One color per value, equal values sharing a color — feed parameter values in, feed the colors to Appearance.OverrideColor per group, and use the uniqueValues/uniqueColors legend for reports. Optional own palette (cycled).

InputTypeDefaultWhat it does
values requiredany[]—One value per element (property values, numbers, names, ...).
colorsany[]nullOptional palette: colors or "#RRGGBB" strings, used in order and cycled.
OutputType
colorsColor[]
uniqueValuesany
uniqueColorsColor[]

Returns: A color per input value, and the distinct values with their colors (index-aligned legend).

color by value parameter property categorical legend map group

Color.Components

Splits a color into its red, green, blue and alpha channels (0-255).

InputTypeDefaultWhat it does
color requiredColor—The color to decompose.
OutputType
redinteger
greeninteger
blueinteger
alphainteger

Returns: Dictionary with "red", "green", "blue" and "alpha" values (0-255).

deconstruct channels rgb argb

Color.ContrastText

Black or white, whichever reads better on a background color (WCAG contrast) — for labels on coloured fills and legends.

InputTypeDefaultWhat it does
background requiredColor—The fill color the text will sit on.
OutputTypeWhat it gives
colorColorOpaque black or opaque white.

contrast text label legible readable accessibility wcag black or white foreground

Color.Darken

Makes a color darker by shifting its HSL lightness down by amount (0-1, clamped); alpha is kept.

InputTypeDefaultWhat it does
color requiredColor—The color to darken.
amountnumber0.2How much lightness to remove, 0 (none) to 1 (black); clamped.
OutputTypeWhat it gives
colorColorThe darker color.

darker shade dim lightness hsl

Color.FromHex

Parses a hex color string ("#RRGGBB" or "#AARRGGBB").

InputTypeDefaultWhat it does
hex requiredstring—The hex string, e.g. "#FF8800".
OutputTypeWhat it gives
colorColorThe parsed color.

hex html web parse

Color.Gradient

A list of N colors evenly blended between two colors (endpoints included; defaults blue to red) — for heat-map style legends and value ramps.

InputTypeDefaultWhat it does
count requiredinteger—How many colors to generate (at least 1).
startColornullFirst color of the gradient (empty = blue).
endColornullLast color of the gradient (empty = red).
OutputTypeWhat it gives
colorsColor[]The gradient colors, start to end.

gradient ramp blend range between interpolate list series

Color.Invert

Inverts a color's red, green and blue channels (the photographic negative); alpha is kept.

InputTypeDefaultWhat it does
color requiredColor—The color to invert.
OutputTypeWhat it gives
colorColorThe inverted color.

negative opposite complement flip reverse

Color.Lerp

Interpolates between two colors (t clamped to 0-1).

InputTypeDefaultWhat it does
start requiredColor—Color at t = 0.
end requiredColor—Color at t = 1.
t requirednumber—Interpolation parameter (clamped to 0–1).
OutputTypeWhat it gives
colorColorThe interpolated color.

interpolate blend gradient mix

Color.Lighten

Makes a color lighter by shifting its HSL lightness up by amount (0-1, clamped); alpha is kept.

InputTypeDefaultWhat it does
color requiredColor—The color to lighten.
amountnumber0.2How much lightness to add, 0 (none) to 1 (white); clamped.
OutputTypeWhat it gives
colorColorThe lighter color.

lighter brighten tint pale lightness hsl

Color.Palette

A named palette as a list of colors: colourblind-safe, tableau, pastel, status (green/amber/red/grey) or the viridis, heat and grey ramps interpolated to count; fixed palettes cycle past their size.

InputTypeDefaultWhat it does
namestring"colourblind"Palette name: colourblind, tableau, pastel, status, viridis, heat or grey.
countinteger8How many colors to return (1–256).
OutputTypeWhat it gives
colorsColor[]The palette colors.

palette scheme colourblind colorblind okabe ito tableau viridis heatmap gray ramp categorical legend list

Color.Random

A pseudo-random color, stable per seed: the same seed always gives the same color (re-runs stay consistent); change the seed for another one.

InputTypeDefaultWhat it does
seedinteger0Any number; each seed maps to one fixed color.
OutputTypeWhat it gives
colorColorThe color.

random seed generate any

Color.RandomList

A list of visually distinct pseudo-random colors (golden-angle hues), stable per seed — ideal for coloring N groups apart.

InputTypeDefaultWhat it does
count requiredinteger—How many colors to generate (at least 1).
seedinteger0Any number; each seed yields one fixed sequence.
OutputTypeWhat it gives
colorsColor[]The colors.

random list palette distinct generate series

Color.ToHex

Formats a color as hex text, "#RRGGBB" (or "#AARRGGBB" with includeAlpha) — the reverse of Color.FromHex.

InputTypeDefaultWhat it does
color requiredColor—The color to format.
includeAlphabooleanfalseTrue to prefix the alpha channel ("#AARRGGBB"); false drops it ("#RRGGBB").
OutputTypeWhat it gives
hexstringThe hex text.

hex html web string text format css

Color.ToHSV

Splits a color into hue (degrees, 0-360), saturation and value (0-1); greys have hue 0.

InputTypeDefaultWhat it does
color requiredColor—The color to decompose.
OutputType
huenumber
saturationnumber
valuenumber

Returns: Dictionary with "hue" (0–360, 0 for greys), "saturation" and "value" (0–1).

hsv hsb hue saturation brightness deconstruct components

Color.WithAlpha

Returns a color with its alpha (opacity) replaced, 0 = transparent to 255 = opaque; red, green and blue are unchanged.

InputTypeDefaultWhat it does
color requiredColor—The color to change.
alpha requiredinteger—The new alpha, 0 (transparent) to 255 (opaque); clamped.
OutputTypeWhat it gives
colorColorThe color with the new alpha.

alpha opacity transparency transparent set
