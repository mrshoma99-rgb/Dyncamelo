36 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Number.Format

Formats a number as text with fixed decimals, an optional thousands separator and a prefix/suffix (invariant culture).

InputTypeDefaultWhat it does
number requirednumber—The number to format.
decimalsinteger2Digits after the decimal point, 0 to 15 (the number is rounded).
thousandsSeparatorbooleanfalseTrue to group the digits in thousands with ",".
prefixstring""Text placed before the number (and its sign), e.g. "EUR ".
suffixstring""Text placed after the number, e.g. " m2".
OutputTypeWhat it gives
textstringThe formatted text.

round decimals currency unit thousands tostring display format
