For developers

Writing your own nodes

Table

28 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Table.AddColumn

Adds a column at the end: a list with one value per row, or a single value repeated on every row.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
name requiredstring—The new column's name.
values requiredany—A list with one value per row, or a single value repeated on every row.
OutputTypeWhat it gives
tableDyncameloTableThe table with the column added at the end.

add column append new field constant

Table.AddFormulaColumn

Adds a column calculated per row from the others, e.g. "Width * Height * Length / 1000000000" (same formula language as Math.Formula; [Names with spaces] in brackets).

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
name requiredstring—The new column's name.
formula requiredstring—A formula over the column names, e.g. Width * Height or [Fire Rating] / 60 (names with spaces in square brackets).
OutputTypeWhat it gives
tableDyncameloTableThe table with the calculated column added at the end.

formula calculated computed column expression volume area

Table.Column

The cells of one column, top to bottom — wire it into List.Sum, List.CountBy, Search or a property writer.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
column requiredstring—The column name.
OutputTypeWhat it gives
valuesany[]The cells of that column, top to bottom.

column field values extract pick

Table.Concat

Stacks tables one below the other, matching columns by name; a column one table lacks is left empty — weekly snapshots, one table per model.

InputTypeDefaultWhat it does
tables any number of wires requiredany[]—The tables, top first (wire several into the one socket).
OutputTypeWhat it gives
tableDyncameloTableOne table with every column of every table (matched by name; missing cells are empty).

append union stack merge combine rbind

Table.Distinct

Keeps only the first row for each distinct value (of the given columns, or of the whole row).

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
columnsstring""Columns that must differ (separated by commas); leave empty to compare whole rows.
OutputTypeWhat it gives
tableDyncameloTableThe table with only the first row of each kind.

unique duplicates dedupe remove duplicates distinct

Table.Filter

Splits a table by a test on one column — Level == "L02", Length > 3000, Name matches "W-*" — into the rows that pass and the rows that do not.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
column requiredstring—The column to test.
teststring"=="The test: ==, !=, >, >=, <, <=, contains, !contains, startsWith, endsWith, matches (wildcards * and ?), regex, isNull, notNull, isEmpty, notEmpty.
valueanynullWhat to test against (unused by the null / empty tests).
ignoreCasebooleantrueTrue (default) ignores upper/lower case in text tests.
OutputType
matcheddict
rejecteddict

Returns: The rows that passed and the rows that did not, both as tables.

filter where query select rows search keep

Table.FromColumns

Makes a table from columns: a list of lists, one per column, with optional names — for results that come as parallel lists.

InputTypeDefaultWhat it does
columns requiredany[]—One list per column (they may differ in length; short ones are padded with nulls).
headersany[]nullThe column names (leave unwired for Column 1, Column 2 …).
OutputTypeWhat it gives
tableDyncameloTableThe table.

columns parallel lists zip table transpose

Table.FromCsvFile

Reads a CSV file straight into a table (numbers become numbers, everything else stays text).

InputTypeDefaultWhat it does
path requiredstring—The CSV file.
delimiterstring","The cell separator (default a comma).
firstRowIsHeaderbooleantrueTrue (default) takes the first row as the column names.
OutputTypeWhat it gives
tableDyncameloTableThe table.

csv read import load file

Table.FromDictionaries

Makes a table from a list of dictionaries (one row each); the columns are all their keys — property bags become rows.

InputTypeDefaultWhat it does
dictionaries requiredany[]—Dictionaries such as the ones Properties.AsDictionary returns; the columns are all their keys, in order of first appearance.
OutputTypeWhat it gives
tableDyncameloTableThe table.

properties records json dictionary table dataframe

Table.FromExcelFile

Reads an Excel worksheet straight into a table.

InputTypeDefaultWhat it does
path requiredstring—The .xlsx file.
sheetstring""The worksheet name (empty takes the first sheet).
firstRowIsHeaderbooleantrueTrue (default) takes the first row as the column names.
OutputTypeWhat it gives
tableDyncameloTableThe table.

excel xlsx read import load spreadsheet

Table.FromRows

Makes a table from rows of cells and column names (or from the first row) — the doorway from Excel, CSV and list data.

InputTypeDefaultWhat it does
rows requiredany[]—The rows; each row a list of cells (as read by Excel.ReadFromFile or CSV.ReadFromFile).
headersany[]nullThe column names. Leave unwired to name the columns Column 1, Column 2 …, or tick firstRowIsHeader.
firstRowIsHeaderbooleanfalseTrue takes the first row as the column names (when no headers are wired).
OutputTypeWhat it gives
tableDyncameloTableThe table.

create table dataframe rows headers sheet grid

Table.GroupBy

Groups rows by one or more columns and works out count, sum, average, min, max, median, first, last, list or distinct per group — "sum:Volume", "count" — the pivot-table core for quantities.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
by requiredstring—The column(s) to group by, separated by commas; leave empty for one total row.
aggregations requiredany[]—What to work out per group, one text each: count, sum:Volume, average:Length as AvgLength. Functions: count, sum, average, min, max, median, first, last, list, distinct.
OutputTypeWhat it gives
tableDyncameloTableOne row per group: the grouping columns followed by one column per aggregation.

group aggregate summary rollup total sum count pivot takeoff qto

OutputTypeWhat it gives

columns names header fields

How many rows and columns a table has, and its column names.

InputTypeDefaultWhat it does

OutputType
rowCountinteger

size count shape dimensions length

Table.Join

Joins two tables on a key column (inner, left or outer) — add the Excel columns to the model data by GUID or mark. Keys match as text, so 42 and "42" are the same.

InputTypeDefaultWhat it does
left requiredDyncameloTable—The main table.
right requiredDyncameloTable—The table to add columns from.
leftKey requiredstring—The key column of the left table.
rightKeystring""The key column of the right table (leave empty to use the same name as leftKey).
kindstring"inner"inner keeps rows with a match on both sides; left keeps every left row; outer keeps every row of both.
OutputTypeWhat it gives
tableDyncameloTableThe joined table: the left columns, then the right columns (a repeated name gets " (right)").

join merge lookup vlookup combine match relate

Table.JoinByKey

Joins spreadsheet rows to a key list: one matched row per key (null when unmatched), plus the keys that matched nothing.

InputTypeDefaultWhat it does
rows requiredany[]—Table rows; each row a list of cells (e.g. from Excel.ReadFromFile).
headers requiredany[]—Column headers, one per cell column.
keys requiredany[]—Keys to look up, e.g. element GUIDs or mark values.
keyColumn requiredstring—Name of the header column holding the keys.
OutputType
matchedRowsany
unmatchedKeysany

Returns: Dictionary with "matchedRows" (parallel to keys; null when unmatched) and "unmatchedKeys".

join lookup vlookup merge link table excel csv

Table.Pivot

Cross-tabulates: rows from one column, columns from another, each cell the sum (or count, average …) of a third — clashes by level and status.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
rowColumn requiredstring—The column whose values become the rows.
columnColumn requiredstring—The column whose values become the new columns.
valueColumnstring""The column to total in each cell (not needed for count).
aggregationstring"sum"How to combine: sum (default), count, average, min, max, first, last.
OutputTypeWhat it gives
tableDyncameloTableOne row per row value, one column per column value.

pivot cross-tab matrix crosstab summary levels by status

Table.Slice

Takes count rows from a starting row (count -1 takes all the rest) — the first 10 rows: start 0, count 10.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
startinteger0The first row to take, counting from 0.
countinteger-1How many rows (-1 takes all the rest).
OutputTypeWhat it gives
tableDyncameloTableThe rows from start on, at most count of them.

take skip head top limit page subset

Table.Sort

Sorts the rows by one or more columns ("Level, -Length" sorts by level, then longest first); numbers numerically, text alphabetically, empty cells last.

InputTypeDefaultWhat it does
table requiredDyncameloTable—The table.
columns requiredstring—Columns to sort by, separated by commas; add " desc" or a leading "-" for largest first: Level, -Length.
descendingbooleanfalseTrue sorts every column largest first (a column can still opt out with " asc").
OutputTypeWhat it gives
tableDyncameloTableThe sorted table; empty cells go last and equal rows keep their order.

sort order rank arrange ascending descending
