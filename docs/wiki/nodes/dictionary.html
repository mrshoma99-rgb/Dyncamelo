Writing your own nodes

Dictionary

13 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Dictionary.ByKeysValues

Creates a dictionary from a list of keys and a list of values of the same length.

InputTypeDefaultWhat it does
keys requiredany[]—The keys (converted to strings).
values requiredany[]—The values, one per key.
OutputTypeWhat it gives
dictionarydictThe new dictionary.

map hash keyvalue

Dictionary.ContainsKey

Tests whether a dictionary has the given key (case-sensitive).

InputTypeDefaultWhat it does
dictionary requiredIDictionary—The dictionary to look in.
key requiredstring—The key to look for.
OutputTypeWhat it gives
hasKeybooleanTrue when the dictionary has the key.

has exists key lookup contains map

Dictionary.Count

Returns the number of entries in a dictionary.

InputTypeDefaultWhat it does
dictionary requiredIDictionary—The dictionary to measure.
OutputTypeWhat it gives
countintegerThe number of keys.

size length number entries keys map

Dictionary.FromRows

Builds a dictionary from a list of [key, value] rows (a later row wins for a repeated key).

InputTypeDefaultWhat it does
rows requiredany[]—A list of rows, each a list with the key in cell 0 and the value in cell 1.
OutputTypeWhat it gives
dictionarydictThe new dictionary.

pairs table rows keyvalue create columns map

Dictionary.Invert

Swaps keys and values into a new dictionary (values become text keys; for equal values the last entry wins).

InputTypeDefaultWhat it does
dictionary requiredIDictionary—The dictionary to invert.
OutputTypeWhat it gives
dictionarydictA new dictionary from value text to the old key.

reverse swap flip reverse lookup map

Dictionary.Keys

Returns all keys of a dictionary as a list.

InputTypeDefaultWhat it does
dictionary requiredIDictionary—The dictionary to read from.
OutputTypeWhat it gives
keysstring[]The keys as a list of strings.

names fields map

Dictionary.Merge

Combines several dictionaries into a new one; for a repeated key the later dictionary wins.

InputTypeDefaultWhat it does
dictionaries any number of wires requiredany[]—The dictionaries to combine, earliest first.
OutputTypeWhat it gives
dictionarydictA new dictionary with the keys of all of them.

combine join union overlay update defaults map

Dictionary.RemoveKey

Returns a copy of the dictionary without the given key (a missing key is fine).

InputTypeDefaultWhat it does
dictionary requiredIDictionary—The dictionary to copy.
key requiredstring—The key to leave out.
OutputTypeWhat it gives
dictionarydictA new dictionary without the key.

delete drop remove omit without map

Dictionary.SetValueAtKey

Returns a copy of the dictionary with the given key set or updated.

InputTypeDefaultWhat it does
dictionary requiredIDictionary—The dictionary to copy.
key requiredstring—The key to set.
value requiredany—The value to store under the key.
OutputTypeWhat it gives
dictionarydictA new dictionary with the key set.

set update insert put map
