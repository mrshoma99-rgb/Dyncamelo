For developers

Writing your own nodes

Navisworks: Document

9 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Application.Version

The running Navisworks product name and API version (report headers, compatibility checks).

No inputs.

OutputType
productstring
apiVersionstring

Returns: Product name (e.g. "Navisworks Manage 2024") and "major.minor" API version.

application version product api navisworks

Document.AppendFiles

Appends design files to the document — Directory.GetFiles → Document.AppendFiles → Export.NWD is the Navisworks Batch Utility in three nodes. Cached model items from earlier runs are invalidated.

InputTypeDefaultWhat it does
filePaths requiredstring[]—The files to append, in order (e.g. from Directory.GetFiles).
documentDocumentnullThe document (defaults to the active document).
OutputType
documentDocument
modelsModelItem[]

Returns: The document and the newly appended models.

document append files add batch federate combine

Document.Current

The active Navisworks document.

No inputs.

OutputTypeWhat it gives
documentDocumentThe active document.

document active current navisworks

Document.Info

File name, title, display units and model count of a document.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputType
fileNamefile
titlestring
unitsstring
modelCountinteger

Returns: File name, title, units and model count.

document info filename title units

Document.Merge

Merges another Navisworks file into the document with duplicate resolution — pulls a colleague's review artifacts (sets, viewpoints, comments) into yours. Not a model-diff tool. Cached model items from earlier runs are invalidated.

InputTypeDefaultWhat it does
filePath requiredstring—The .nwf/.nwd to merge (e.g. a colleague's review file).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
documentDocumentThe document, with the file's contents merged in.

document merge combine review duplicate nwf

Document.Models

The models (appended source files) loaded in a document.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
modelsModel[]All loaded models.

document models files appended

Document.Open

Opens a file into the document, REPLACING its current contents (the headless batch driver). Every model item from before the open is invalidated — re-query items downstream of this node.

InputTypeDefaultWhat it does
filePath requiredstring—The file to open (.nwd/.nwf/.nwc or any appendable design format).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
documentDocumentThe document, now holding the opened file.

document open file load batch nwd nwf

Document.Refresh

Refreshes every linked/appended file from disk — Home > Refresh, scriptable. Returns true when anything was updated. Cached model items from earlier runs are invalidated.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
updatedbooleanTrue when any file was updated from disk.

document refresh update reload linked files

Document.Save

Saves the document as .nwf (references) or .nwd (published snapshot) to the given path.

InputTypeDefaultWhat it does
filePath requiredstring—Destination path ending in .nwf or .nwd; the directory is created when missing.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
filePathstringThe written file path.

document save nwf nwd publish write
