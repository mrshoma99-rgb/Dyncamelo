Writing your own nodes

Navisworks: TimeLiner

10 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

TimeLiner.AutoAttachByProperty

For every TimeLiner task (subtasks included), finds all items whose property value equals the task name and attaches them — the UI's "Auto-Attach Using Rules", scriptable. Replaces each matched task's existing attachment; tasks with no matching items are left untouched and reported in unmatchedTasks.

InputTypeDefaultWhat it does
category requiredstring—Property category display name (e.g. "Element" or a Properties.SetCustom tab). Internal names do not match.
property requiredstring—Property display name (e.g. "Task Name"). Internal names do not match.
documentDocumentnullThe document (defaults to the active document).
OutputType
attachedCountinteger
unmatchedTasksany

Returns: How many tasks received attachments, and the names of tasks with no matching items.

timeliner auto attach rules 4d link schedule property

TimeLiner.Tasks

All TimeLiner tasks in a document, with subtasks flattened into one list.

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
tasksTimelinerTask[]Every task, with the task hierarchy flattened (subtasks included).

timeliner tasks schedule 4d all

TimelinerTask.AttachSet

Attaches a saved selection/search set to a task as a LIVE link (like Attach Set in the UI) — the core 4D-linking automation.

InputTypeDefaultWhat it does
task requiredTimelinerTask—The stored TimeLiner task (from TimeLiner.Tasks or TimelinerTask.Create).
setName requiredstring—The saved set's display name (folders are searched too).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
taskTimelinerTaskThe updated stored task. Lace over task/set-name lists for bulk 4D linking.

timeliner task attach set link 4d

TimelinerTask.Create

Creates a top-level TimeLiner task with planned dates and optionally attaches model items.

InputTypeDefaultWhat it does
name requiredstring—Display name for the new task.
plannedStart requireddatetime—Planned start date.
plannedEnd requireddatetime—Planned end date.
itemsModelItem[]nullModel items to attach (optional).
taskTypestring"Construct"Simulation task type name: "Construct", "Demolish" or "Temporary".
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
taskTimelinerTaskThe stored TimeLiner task.

timeliner task create new schedule 4d

TimelinerTask.Delete

Deletes a TimeLiner task together with its subtasks. Returns false (and changes nothing) when the task is not in the document, so a clean-up step can run twice.

InputTypeDefaultWhat it does
task requiredTimelinerTask—The stored TimeLiner task to delete.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
deletedbooleanTrue when the task was removed; false when it is not in the document.

timeliner task delete remove clean 4d schedule

OutputType

plannedStartdatetime
plannedEnddatetime

actualEnddatetime

Returns: Name, id, planned/actual dates, task type and progress.

TimelinerTask.Items

The model items attached to a TimeLiner task. Search and set attachments are re-evaluated.

InputTypeDefaultWhat it does
task requiredTimelinerTask—The TimeLiner task.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemsModelItem[]The attached items (search/set attachments are evaluated).

timeliner task items attached selection

TimelinerTask.SetActual

Sets a task's ACTUAL start and end dates (the planned dates are untouched; use TimelinerTask.SetDates for those) — record what happened on site next to the plan.

InputTypeDefaultWhat it does
task requiredTimelinerTask—The stored TimeLiner task.
start requireddatetime—Actual start date.
end requireddatetime—Actual end date.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
taskTimelinerTaskThe updated stored task. Lace over lists for bulk updates.

timeliner task actual dates start end schedule 4d update

TimelinerTask.SetDates

Updates a task's planned start/end dates in place — bulk schedule edits without a re-import.

InputTypeDefaultWhat it does
task requiredTimelinerTask—The stored TimeLiner task.
plannedStart requireddatetime—New planned start date.
plannedEnd requireddatetime—New planned end date.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
taskTimelinerTaskThe updated stored task. Lace over lists for bulk schedule updates.

timeliner task dates schedule update planned

TimelinerTask.SetProgress

Sets a task's percent complete (0-100; anything outside is clamped) — update progress from a site report in bulk. Lace over tasks and percentages.

InputTypeDefaultWhat it does
task requiredTimelinerTask—The stored TimeLiner task (from TimeLiner.Tasks or TimelinerTask.Create).
percent requirednumber—Percent complete; values outside 0-100 are clamped to 0 or 100.
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
taskTimelinerTaskThe updated stored task. Lace over task / percent lists for bulk progress updates.

timeliner task progress percent complete status 4d update
