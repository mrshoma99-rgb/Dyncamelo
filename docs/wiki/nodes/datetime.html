For developers

Writing your own nodes

DateTime

19 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

DateTime.AddDays

Offsets a date/time by a number of days (fractional and negative values allowed).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to offset.
days requirednumber—Days to add (fractional and negative values allowed).
OutputTypeWhat it gives
dateTimedatetimeThe offset date/time.

offset shift schedule date

DateTime.AddHours

Adds hours to a date/time (fractional and negative values allowed).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to offset.
hours requirednumber—Hours to add (fractional and negative values allowed).
OutputTypeWhat it gives
dateTimedatetimeThe offset date/time.

offset shift schedule hour later earlier time

DateTime.AddMinutes

Adds minutes to a date/time (fractional and negative values allowed).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to offset.
minutes requirednumber—Minutes to add (fractional and negative values allowed).
OutputTypeWhat it gives
dateTimedatetimeThe offset date/time.

offset shift schedule minute later earlier time

DateTime.AddMonths

Adds calendar months to a date/time (the day clamps to the end of a shorter month).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to offset.
months requiredinteger—Months to add (negative values allowed).
OutputTypeWhat it gives
dateTimedatetimeThe offset date/time.

offset shift schedule month later earlier

DateTime.AddYears

Adds calendar years to a date/time (29 February clamps to 28 February in a common year).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to offset.
years requiredinteger—Years to add (negative values allowed).
OutputTypeWhat it gives
dateTimedatetimeThe offset date/time.

offset shift schedule year later earlier

DateTime.AgeInDays

Returns how many days old a date/time is at a reference date/time (reference minus date; fractional days included).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to measure the age of, e.g. when a clash was created.
reference requireddatetime—The date/time to measure up to, e.g. DateTime.Now.
OutputTypeWhat it gives
daysnumberThe age in days (reference minus dateTime).

age old elapsed since overdue duration days

DateTime.ByDate

Creates a date from year, month and day numbers.

InputTypeDefaultWhat it does
year requiredinteger—Year, e.g. 2026.
month requiredinteger—Month, 1-12.
day requiredinteger—Day of month, 1-31.
OutputTypeWhat it gives
dateTimedatetimeThe date at midnight.

construct ymd calendar date

DateTime.Compare

Compares two date/times: -1 when the first is earlier, 0 when equal, 1 when it is later.

InputTypeDefaultWhat it does
a requireddatetime—The first date/time.
b requireddatetime—The second date/time.
OutputTypeWhat it gives
resultinteger-1 when a is earlier than b, 0 when they are equal, 1 when a is later than b.

earlier later before after equal order sort

DateTime.Components

Splits a date/time into year, month, day, hour, minute, second, English weekday name, day of year, ISO week, ISO year and quarter.

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to split.
OutputType
yearinteger
monthinteger
dayinteger
hourinteger
minuteinteger
secondinteger
weekdaystring
dayOfYearinteger
isoWeekinteger
isoYearinteger
quarterinteger

Returns: Dictionary with "year", "month", "day", "hour", "minute", "second", "weekday", "dayOfYear", "isoWeek", "isoYear" and "quarter".

deconstruct parts year month weekday week number iso week quarter

DateTime.DaysBetween

Returns the signed number of days between two date/times (end minus start).

InputTypeDefaultWhat it does
start requireddatetime—The starting date/time.
end requireddatetime—The ending date/time.
OutputTypeWhat it gives
daysnumberThe signed day difference.

difference duration span elapsed

DateTime.EndOf

Returns the last millisecond of the day, week, month, quarter or year containing a date/time (start of the next period minus 1 ms).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time inside the period.
unitstring"week""day", "week", "month", "quarter" or "year" (any case).
firstDayOfWeekstring"Monday""Monday" or "Sunday" (any case); only used for "week".
OutputTypeWhat it gives
dateTimedatetimeThe start of the next period minus one millisecond.

ceiling period last day finish deadline week month quarter year

DateTime.Format

Formats a date/time as text using a .NET format string (invariant culture).

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time to format.
formatstring"yyyy-MM-dd HH:mm:ss".NET date format string.
OutputTypeWhat it gives
textstringThe formatted text.

tostring date time pattern

DateTime.FromUnixSeconds

Converts Unix seconds since 1970-01-01 UTC to a (UTC) date/time.

InputTypeDefaultWhat it does
seconds requirednumber—Seconds since the Unix epoch (negative before 1970).
OutputTypeWhat it gives
dateTimedatetimeThe date/time, with kind UTC.

epoch timestamp posix unix seconds convert

DateTime.Now

Returns the current local date and time (captured at execution).

No inputs.

OutputTypeWhat it gives
dateTimedatetimeThe current local date and time.

today current clock time

DateTime.Parse

Parses text as a date/time, optionally with an exact .NET format string.

InputTypeDefaultWhat it does
text requiredstring—The text to parse.
formatstring""Optional exact .NET date format string.
OutputTypeWhat it gives
dateTimedatetimeThe parsed date/time.

fromstring convert date time

DateTime.Range

Creates a list of dates from a start to an end (both included) with a step in days; at most 100000 items.

InputTypeDefaultWhat it does
start requireddatetime—The first date.
end requireddatetime—The last date (included when the step lands on it).
stepDaysnumber1Days between two items; must be greater than 0.
OutputTypeWhat it gives
datesdatetime[]The dates, in order.

sequence series calendar schedule every days timeline

DateTime.StartOf

Returns midnight at the start of the day, week, month, quarter or year containing a date/time.

InputTypeDefaultWhat it does
dateTime requireddatetime—The date/time inside the period.
unitstring"week""day", "week", "month", "quarter" or "year" (any case).
firstDayOfWeekstring"Monday""Monday" or "Sunday" (any case); only used for "week".
OutputTypeWhat it gives
dateTimedatetimeThe first instant (00:00:00) of the period.

floor truncate period first day beginning week month quarter year

DateTime.Today

Returns today's local date at midnight (captured at execution).

No inputs.

OutputTypeWhat it gives
dateTimedatetimeThe local date at 00:00:00.

current date now midnight day
