For developers

Writing your own nodes

Navisworks: Units

4 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Units.All

Every unit name accepted by Units.Convert and Units.ScaleFactor.

No inputs.

OutputTypeWhat it gives
namesstring[]The valid unit names (e.g. "Meters", "Feet", "Millimeters").

units all names list valid

Units.Convert

Converts a length value from one unit to another (e.g. Feet to Millimeters).

InputTypeDefaultWhat it does
value requirednumber—The value to convert.
fromUnits requiredUnits—Source units (e.g. "Feet").
toUnits requiredUnits—Target units (e.g. "Millimeters").
OutputTypeWhat it gives
valuenumberThe converted value.

units convert length conversion

Units.Current

The display units of a document (all API lengths, areas and volumes use them).

InputTypeDefaultWhat it does
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
unitsstringThe unit name, e.g. "Meters" or "Feet".

units current document meters feet

Units.ScaleFactor

The multiplier that converts a length from one unit to another.

InputTypeDefaultWhat it does
fromUnits requiredUnits—Source units (e.g. "Feet"); unit names as in Units.Current.
toUnits requiredUnits—Target units (e.g. "Millimeters").
OutputTypeWhat it gives
factornumberThe scale factor (multiply a source value by it).

units scale factor conversion
