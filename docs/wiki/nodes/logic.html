Writing your own nodes

Logic

18 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

And

Returns true only when both inputs are true.

InputTypeDefaultWhat it does
a requiredboolean—First operand.
b requiredboolean—Second operand.
OutputTypeWhat it gives
resultbooleanTrue when both operands are true.

&& conjunction boolean

Equals

Tests whether two values are equal (numbers compare by value regardless of numeric type).

InputTypeDefaultWhat it does
a requiredany—First value.
b requiredany—Second value.
OutputTypeWhat it gives
resultbooleanTrue when the values are considered equal.

== equal same compare

If

Returns one of two values depending on a boolean condition.

InputTypeDefaultWhat it does
test requiredboolean—The condition to evaluate.
trueValue requiredany—Value returned when the condition is true.
falseValue requiredany—Value returned when the condition is false.
OutputTypeWhat it gives
resultanyEither trueValue or falseValue.

condition branch ternary switch

IsNull

True when the value is null — with @L1 on the input it tests a whole list element-wise, giving the bool mask for List.FilterByBoolMask (pair with Not to keep the non-nulls). The input port is untyped, so a list arrives whole unless levels are set.

InputTypeDefaultWhat it does
value requiredany—The value to test. To test each element of a list, set this input's List Levels to @L1.
OutputTypeWhat it gives
isNullbooleanTrue when the value is null.

null is check missing empty mask test

IsNullOrEmpty

True when the value is null, an empty string, an empty list or an empty dictionary — the guard for "did anything come out?" checks before If branches. NOTE: wired to a list directly it tests the LIST (empty or not); set the input's List Levels to @L1 to test each element instead.

InputTypeDefaultWhat it does
value requiredany—The value to test: null, an empty string, an empty list and an empty dictionary all count as empty. To test each element of a list, set this input's List Levels to @L1.
OutputTypeWhat it gives
isEmptybooleanTrue when the value is null or empty.

null empty is check blank missing guard test

Logic.Choose

Picks one of several options by position (0 = first) — a multi-way If.

InputTypeDefaultWhat it does
index requiredinteger—Which option, counting from 0.
options any number of wires requiredany[]—The options (wire several nodes into the one socket, or a list).
OutputTypeWhat it gives
valueanyThe option at that index.

select pick switch index option multiplexer

Logic.Compare

Compares two values — numbers, text or dates — with a test chosen from a list (==, >, contains, matches, regex …). Text that reads as a number is compared as a number.

InputTypeDefaultWhat it does
a requiredany—The value to test.
banynullWhat to test it against (unused by the isNull / notNull / isEmpty / notEmpty tests).
teststring"=="The test: ==, !=, >, >=, <, <=, contains, !contains, startsWith, endsWith, matches (wildcards * and ?), regex, isNull, notNull, isEmpty, notEmpty.
ignoreCasebooleantrueTrue (default) ignores upper/lower case when comparing text.
OutputTypeWhat it gives
resultbooleanTrue when the test passes.

compare greater less equal date text contains wildcard regex test

Logic.IsBetween

True when a number, text or date lies between a lower and an upper bound (bounds included by default).

InputTypeDefaultWhat it does
value requiredany—The value to test (number, text or date).
min requiredany—The lower bound.
max requiredany—The upper bound.
inclusivebooleantrueTrue (default) counts the bounds themselves as inside.
OutputTypeWhat it gives
resultbooleanTrue when the value is within the range.

range within between inside interval tolerance

Logic.Switch

Gives the result that goes with the first case equal to the value, otherwise the fallback — a status-to-colour or code-to-name mapping.

InputTypeDefaultWhat it does
value requiredany—The value to look for.
cases requiredany[]—The values it can be.
results requiredany[]—What to give for each case (same length as the cases).
fallbackanynullWhat to give when no case matches (nothing by default).
OutputTypeWhat it gives
valueanyThe result for the first matching case, or the fallback.

case match map lookup translate switch select

Logic.TypeOf

Names the kind of a value — number, text, boolean, datetime, list, dictionary, null or the object's type — for debugging what a node really returns.

InputTypeDefaultWhat it does
value requiredany—Any value.
OutputTypeWhat it gives
typestringOne of: null, number, text, boolean, datetime, list, dictionary, or the type's name.

type kind debug inspect what is this class
