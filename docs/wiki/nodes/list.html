List.Chop

Chops a list into consecutive sublists: one length chops evenly ([1..7] by 3 → [1,2,3],[4,5,6],[7]); a list of lengths is applied in sequence and repeats until the input runs out (Dynamo behavior).

InputTypeDefaultWhat it does
list requiredany[]—The list to chop.
lengths requiredany[]—Sublist length(s): one number chops evenly; a list of numbers is applied in sequence and repeats until the list is used up.
OutputTypeWhat it gives
listsany[]The sublists (the last one may be shorter).

chop split partition chunk sublists group

List.Clean

Removes null elements from a list, at every nesting level — the mop-up after laced calls that emitted nulls for missing elements (a yellow node badge points here). removeEmptyLists also drops sublists left empty. Dynamo users: same idea as List.Clean.

InputTypeDefaultWhat it does
list requiredany[]—The list to clean (nested lists are cleaned recursively).
removeEmptyListsbooleantrueTrue also drops sublists that are (or become) empty; false keeps them as empty lists.
OutputTypeWhat it gives
listany[]The cleaned list.

clean null remove nulls compact purge empty filter

valueanynullWhat to test against (not used by the isNull / notNull / isEmpty / notEmpty tests).

OutputType
