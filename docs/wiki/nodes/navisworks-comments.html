Writing your own nodes

Navisworks: Comments

3 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

SavedItem.AddComment

Adds a comment to a saved viewpoint, selection/search set, folder, clash result or result group — the Review-tab Comments feature, scriptable; lace over results for review notes in bulk.

InputTypeDefaultWhat it does
item requiredSavedItem—The saved item (a viewpoint, selection/search set, one of their folders, or a clash result or group).
body requiredstring—The comment text.
statusstring"New""New", "Active", "Approved" or "Resolved".
authorstring""Comment author ("" uses the Navisworks user name).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemSavedItemThe stored item the comment was added to (pass-through for chaining).

comment add review note viewpoint set annotate

SavedItem.ClearComments

Deletes every comment on a saved viewpoint, selection/search set or folder (replace-all with an empty thread). Rebuild the thread afterwards with SavedItem.AddComment.

InputTypeDefaultWhat it does
item requiredSavedItem—The saved item (a viewpoint, selection/search set, or one of their folders).
documentDocumentnullThe document (defaults to the active document).
OutputTypeWhat it gives
itemSavedItemThe stored item (pass-through for chaining).

comment clear delete remove review reset

SavedItem.Comments

The comment thread on any saved item (viewpoint, set, folder, clash test): bodies, authors, statuses and creation dates, index-aligned.

InputTypeDefaultWhat it does
item requiredSavedItem—The saved item (viewpoint, set, folder or clash test).
OutputType
bodiesstring[]
authorsstring[]
statusesstring[]
datesdatetime[]

Returns: Index-aligned comment bodies, authors, statuses and creation dates.

comment comments read review thread notes
