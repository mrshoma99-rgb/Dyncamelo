Writing your own nodes

Navisworks: Export

14 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

BCF.ExportIssues

Exports clash results (or saved viewpoints) as BCF 2.1 issues (.bcfzip: markup, camera viewpoint, component GUIDs, snapshot) — the vendor-neutral bridge into BIMcollab / Konekt / Revizto / ACC. Components use the IFC GlobalId when present, else the InstanceGuid (lossy for non-IFC sources). Cameras are written in meters per the BCF convention.

InputTypeDefaultWhat it does
filePath requiredstring—Destination .bcfzip (or .bcf) path; the directory is created when missing.
resultsSavedItem[]nullClash results or result groups to export as topics (from ClashTest.Results).
viewpointsSavedViewpoint[]nullSaved viewpoints to export as topics (instead of, or besides, results).
includeSnapshotsbooleantrueTrue to render a snapshot.png per topic (slower on big result lists).
statusMapIDictionarynullOptional Navisworks-status → BCF-topic-status map (e.g. {"New": "Open", "Approved": "Closed"}). Unmapped statuses use the default map: New/Active → Open, Reviewed → In Progress, Approved/Resolved → Closed.
documentDocumentnullThe document (defaults to the active document).
OutputType
filePathfile
topicCountinteger

Returns: The written path and the number of topics exported.

bcf export issues bcfzip bimcollab revizto konekt acc exchange

BCF.ImportIssues

Reads a BCF 2.0/2.1 package: per topic title/status/description/comments/component GUIDs/camera, plus the model items each topic's components resolve to (matched by IFC GlobalId, then InstanceGuid). Optionally applies one topic's camera to the current view — feeds ClashResult.SetStatus and Selection.SetCurrent for the issue-sync return leg.

InputTypeDefaultWhat it does
filePath requiredstring—The .bcfzip (or .bcf) file to read.
applyCameraTopicIndexinteger-1Index of a topic whose camera should be applied to the current view (-1 = leave the camera alone).
documentDocumentnullThe document (defaults to the active document).
OutputType
topicsdict[]
modelItemsModelItem[]

Returns: Topic dictionaries and, per topic, the model items its component GUIDs resolve to.

bcf import issues bcfzip read roundtrip exchange

Lists the friendly IFC class names (Wall, Beam, Door, …) accepted by Export.IfcSetClassMap.

No inputs.

OutputTypeWhat it gives

InputTypeDefaultWhat it does

eastingsnumber0Custom base-point easting in metres (Custom mode).
northingsnumber0Custom base-point northing in metres (Custom mode).
elevationnumber0Custom base-point elevation in metres (Custom mode).
rotationDegreesnumber0Grid/true-north rotation, recorded in IFC4 georeferencing.

Export.IfcRoles

Maps Navisworks source properties to IFC roles — Type→IfcElementType, Level→IfcBuildingStorey, Material→IfcMaterial, Classification→IfcClassificationReference — for Export.ToIfc.

InputTypeDefaultWhat it does
typePropertystring""Property whose value groups occurrences into IfcElementType (+ ObjectType).
typeCategorystring""Category carrying the type property (blank = any).
levelPropertystring""Property whose value assigns each element to an IfcBuildingStorey.
levelCategorystring""Category carrying the level property (blank = any).
materialPropertystring""Property whose value becomes the IfcMaterial name.
materialCategorystring""Category carrying the material property (blank = any).
classificationPropertystring""Property whose value becomes an IfcClassificationReference (IFC4).
classificationCategorystring""Category carrying the classification property (blank = any).

Export.ToIfc

Exports model items to IFC (IFC4/IFC2x3) via the BIMCamel exporter: spatial tree, instancing, property sets, materials, base quantities and georeferencing.

InputTypeDefaultWhat it does
items any number of wires requiredModelItem[]—The model items to export (resolved to leaf geometry, like the exporter's scope).
filePath requiredstring—Destination .ifc path; the directory is created when missing.
schemastring"IFC4""IFC4" (default) or "IFC2x3".
instancingbooleantrueReuse repeated geometry as IfcMappedItem (smaller files); off writes every mesh in full.
propertiesbooleantrueWrite Navisworks properties as IfcPropertySets.
materialsbooleantrueWrite element colours as IfcSurfaceStyle / IfcMaterial.
quantitiesbooleantrueCompute base quantities (volume/area/length) from the mesh.
unitsstring"Auto"Source units: "Auto" (from the model) or Millimeters/Centimeters/Meters/Feet/Inches.
qualitystring"Balanced""Balanced" (default), "Small file" or "High detail" — sets weld tolerance and coordinate precision.
coordinatesCoordOptionsnullBase-point / georeferencing options from Export.IfcCoordinates (default: geometry origin + georef).
spatialNamesSpatialNamesnullProject/Site/Building/Storey names from Export.IfcSpatialNames (default: sensible names).
rolesPropertyRolesnullType/Level/Material/Classification source-property mapping from Export.IfcRoles.
parameterRulesParamMapRule[]nullProperty rename/relocate rules from Export.IfcParameterRule.
categoryFilterstring[]nullOnly export these property categories (null = all).
classMapdictnullItem→IFC-class overrides from Export.IfcSetClassMap.
splitMegabytesnumber0Split the output into parts near this size (0 = single file).
validatebooleanfalseRun the built-in structural validator on each written file.
documentDocumentnullThe document (defaults to the active document).
OutputType
filePathfile
fileCountinteger
elementCountinteger
triangleCountinteger
fileSizeKbnumber

Returns: The written path(s) and export statistics.

export ifc openbim bim qto ifc4 ifc2x3 bimcamel
