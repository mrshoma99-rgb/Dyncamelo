For developers

Writing your own nodes

Report

2 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

Report.Html

Builds a self-contained HTML report from tables and text ("# Heading" makes a heading) — light and dark, printable, ready for Text.WriteToFile or an e-mail.

InputTypeDefaultWhat it does
title requiredstring—The report title.
sections any number of wires requiredany[]—What goes in the report, top to bottom: tables, text paragraphs ("# Heading" and "## Subheading" make headings), lists and other values (shown as text). Wire several into the one socket.
subtitlestring""A line under the title, e.g. the model name and date.
OutputTypeWhat it gives
htmlstringA complete HTML page.

report html page weekly summary export publish document

Report.Markdown

Builds a Markdown report from tables and text — for Teams, issue trackers and wikis.

InputTypeDefaultWhat it does
title requiredstring—The report title.
sections any number of wires requiredany[]—What goes in the report, top to bottom: tables, text (a "# Heading" line stays a heading) and other values.
subtitlestring""A line under the title.
OutputTypeWhat it gives
markdownstringThe Markdown text.

report markdown md weekly summary wiki document
