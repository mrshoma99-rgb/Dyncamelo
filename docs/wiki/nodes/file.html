Writing your own nodes

File

36 nodes. Every node has its own link: click its name. Types ending in [] are lists; an input with a default is optional.

CSV.AppendToFile

Appends rows to a CSV file (same quoting as CSV.WriteToFile), writing the optional headers only when the file is new or empty.

InputTypeDefaultWhat it does
path requiredstring—The CSV file to append to.
rows requiredany[]—List of rows (each row a list of cell values; a scalar becomes a one-cell row).
delimiterstring","Single-character cell delimiter.
headersany[]nullOptional header cells, written once when the file is new or empty.
OutputTypeWhat it gives
pathstringThe path that was written, for sequencing further file nodes.

csv append add rows table report export

CSV.ReadFromFile

Reads a CSV file into a list of rows (numeric cells become numbers).

InputTypeDefaultWhat it does
path requiredstring—Path to the CSV file.
delimiterstring","Single-character cell delimiter.
OutputTypeWhat it gives
dataany[]List of rows; each row is a list of numbers/strings.

csv table spreadsheet import

CSV.WriteToFile

Writes a list of rows to a CSV file (overwrites; creates missing directories).

InputTypeDefaultWhat it does
path requiredstring—Destination file path.
data requiredany[]—List of rows (each row a list of cell values).
delimiterstring","Single-character cell delimiter.
OutputTypeWhat it gives
pathstringThe path that was written, for sequencing further file nodes.

csv table spreadsheet export

Directory.Create

Creates a folder including any missing parent folders (does nothing when it already exists).

InputTypeDefaultWhat it does
path requiredstring—The folder to create.
OutputTypeWhat it gives
pathstringThe folder path, for sequencing further file nodes.

mkdir make folder new directory

Directory.Delete

Deletes a folder (an empty one, or with its whole content when recursive is true); returns false when it did not exist.

InputTypeDefaultWhat it does
path requiredstring—The folder to delete.
recursivebooleanfalseTrue to delete the folder together with everything inside it.
OutputTypeWhat it gives
deletedbooleanTrue when a folder was deleted; false when there was no such folder.

remove rmdir erase clean folder directory

Directory.Exists

Tests whether a folder exists at the given path.

InputTypeDefaultWhat it does
path requiredstring—The folder path to test.
OutputTypeWhat it gives
existsbooleanTrue when a folder exists at the path (false for files and missing paths).

folder check found present directory

Directory.FindFiles

Finds files under a folder by wildcard (several allowed, separated by ";"), sorted by name, date or size, with an optional limit - the newest file is sortBy modified + descending + limit 1.

InputTypeDefaultWhat it does
path requiredstring—The folder to search.
patternstring"*"Wildcard filter on the file name ("*" and "?"); several patterns can be separated by ";" (e.g. "*.nwd;*.nwf").
recursivebooleantrueTrue (default) to search sub-folders too.
sortBystring"name"name (full path, alphabetical), modified, created or size.
descendingbooleanfalseTrue to reverse the order (newest / largest first).
limitinteger0Keep only the first N files after sorting; 0 keeps all.
OutputTypeWhat it gives
filesstring[]The full file paths in the requested order.

search find newest latest recursive list wildcard files directory

Directory.GetDirectories

Lists the sub-folders of a folder as full paths (optionally filtered by a wildcard such as "2026*" and optionally at every depth).

InputTypeDefaultWhat it does
path requiredstring—The folder to list.
patternstring"*"Wildcard filter on the folder name ("*" and "?"); several patterns can be separated by ";".
recursivebooleanfalseTrue to include sub-folders of sub-folders.
OutputTypeWhat it gives
directoriesstring[]The full folder paths, sorted alphabetically.

folders subfolders list browse directory tree

Directory.GetFiles

Lists the files in a folder (optionally filtered by a wildcard such as "*.nwd").

InputTypeDefaultWhat it does
path requiredstring—The folder to list.
patternstring"*.*"Wildcard filter; the default matches every file.
OutputTypeWhat it gives
filesstring[]The full file paths, sorted.

folder list batch directory browse

Excel.ReadFromFile

Reads an .xlsx worksheet into rows + headers (dates arrive as Excel serial numbers; .xls is not supported).

InputTypeDefaultWhat it does
path requiredstring—Path to the .xlsx file.
sheetstring""Worksheet name; empty selects the first sheet.
hasHeadersbooleantrueTrue when the first row is a header row (it is split off into "headers").
OutputType
rowsany
headersstring[]
sheetNamesstring[]

Returns: Dictionary with "rows", "headers" and "sheetNames".

xlsx excel spreadsheet workbook table import

Excel.WriteToFile

Writes rows (+ optional headers) to an .xlsx worksheet; append adds a sheet to an existing workbook (foreign styles/formulas are not preserved).

InputTypeDefaultWhat it does
path requiredstring—Destination .xlsx path (missing directories are created).
rows requiredany[]—List of rows; each row a list of cell values (scalar rows become single-cell rows).
headersany[]nullOptional header row written before the data rows.
sheetstring"Sheet1"Worksheet name (Excel rules: 1-31 chars, no : \ / ? * [ ]).
appendbooleanfalseTrue to add the sheet to an existing workbook instead of replacing the file.
OutputTypeWhat it gives
pathstringThe path that was written, for sequencing further file nodes.

xlsx excel spreadsheet workbook export save

File.Hash

Computes a checksum of a file's content (SHA256, SHA1 or MD5) as lower-case hex text - handy for change detection.

InputTypeDefaultWhat it does
path requiredstring—The file to hash.
algorithmstring"SHA256"SHA256 (default), SHA1 or MD5, in any case.
OutputTypeWhat it gives
hashstringThe hash as lower-case hexadecimal text.

checksum sha md5 digest change compare fingerprint

File.Info

Reads a file's name, extension, folder, size in bytes and modified / created dates; a missing file gives exists = false and empty values instead of an error.

InputTypeDefaultWhat it does
path requiredstring—The file to inspect.
OutputType
existsboolean
namestring
extensionstring
directoryfile
sizeBytesnumber
modifieddatetime
createddatetime

Returns: Dictionary with "exists", "name", "extension", "directory", "sizeBytes", "modified" and "created".

size date modified created properties stat exists attributes

Log.Write

Appends one line "yyyy-MM-dd HH:mm:ss LEVEL message" (local time) to a log file and returns that line.

InputTypeDefaultWhat it does
path requiredstring—The log file.
message requiredstring—The text to log; line breaks are replaced by " | " so an entry stays on one line.
levelstring"INFO"INFO (default), WARN, ERROR or DEBUG, in any case.
OutputTypeWhat it gives
linestringThe line that was written, e.g. "2026-10-01 10:20:35 INFO message".

log logging audit trail timestamp journal append report

Path.ChangeExtension

Replaces the extension of a path ("a.nwd" + "nwf" gives "a.nwf"); empty text removes the extension.

InputTypeDefaultWhat it does
path requiredstring—The path to change.
extension requiredstring—The new extension, with or without the leading dot; empty text removes the extension.
OutputTypeWhat it gives
pathstringThe path with the new extension.

extension rename replace suffix convert path

Path.Combine

Joins a folder path and a file name with the correct separator.

InputTypeDefaultWhat it does
directory requiredstring—The folder part.
fileName requiredstring—The file (or subpath) part.
OutputTypeWhat it gives
pathstringThe combined path.

join folder filename concat

Path.GetDirectory

Returns the folder part of a path ("C:\Models\site.nwd" gives "C:\Models"); empty text for a root or a bare file name.

InputTypeDefaultWhat it does
path requiredstring—The path to split.
OutputTypeWhat it gives
directorystringThe path without its last part; empty for a drive/root or a bare file name.

folder parent dirname directory path

Path.GetExtension

Returns the extension of a path with its leading dot (".nwd"), or empty text when there is none.

InputTypeDefaultWhat it does
path requiredstring—The path to inspect.
OutputTypeWhat it gives
extensionstringThe extension with its dot (".nwd"); empty when the file name has none.

extension suffix type ext path

Path.GetFileName

Returns the file name of a path including its extension ("C:\Models\site.nwd" gives "site.nwd").

InputTypeDefaultWhat it does
path requiredstring—The path to split, e.g. "C:\Models\site.nwd".
OutputTypeWhat it gives
fileNamestringThe last part of the path ("site.nwd"); empty when the path ends with a separator.

filename basename name split path

Path.GetFileNameWithoutExtension

Returns the file name of a path without its extension ("C:\Models\site.nwd" gives "site").

InputTypeDefaultWhat it does
path requiredstring—The path to split, e.g. "C:\Models\site.nwd".
OutputTypeWhat it gives
namestringThe file name without the last extension ("site").

filename basename stem name split path

Path.GetFullPath

Resolves a path to an absolute path (relative paths start from the current folder); the file does not have to exist.

InputTypeDefaultWhat it does
path requiredstring—The (possibly relative) path.
OutputTypeWhat it gives
pathstringThe absolute path with "." and ".." resolved.

absolute resolve full expand path

Path.GetRelativePath

Expresses a path relative to a base folder; returns the full path when they are on different drives.

InputTypeDefaultWhat it does
path requiredstring—The path to express (absolute, or relative to the current folder).
baseDirectory requiredstring—The folder the result is relative to.
OutputTypeWhat it gives
pathstringThe relative path ("..\other\a.nwd"), "." when both are the same folder, or the full path when they have different roots (e.g. different drives).

relative base make relative path

Path.IsAbsolute

Tests whether a path is absolute (starts at a drive, network share or root) rather than relative.

InputTypeDefaultWhat it does
path requiredstring—The path to test.
OutputTypeWhat it gives
isAbsolutebooleanTrue for "C:\a", "\\server\share" and "/home/a"; false for "a\b", "..\a" and drive-relative "C:a".

absolute relative rooted check path

Path.Normalize

Cleans a path as text: one separator style, no trailing separator, "." and ".." resolved (the disk is never read).

InputTypeDefaultWhat it does
path requiredstring—The path to clean.
OutputTypeWhat it gives
pathstringThe normalized path; "." when a relative path cancels out completely.

clean tidy canonical separator slash simplify path

OutputTypeWhat it gives

overwritebooleanfalseTrue to replace files that already exist; false (default) to fail instead.
OutputTypeWhat it gives

unzip extract decompress unpack archive zip
