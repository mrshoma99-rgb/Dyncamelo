Dyncamelo

Visual programming for Autodesk Navisworks · version {{VERSION}} · by BIMCamel

Dyncamelo lets you build a Navisworks job as a graph of nodes instead of writing code. Add nodes, wire the output of one to the input of the next, and press Run. The graph reads and changes the model you have open: search it, colour it, make selection sets, take quantities out, triage clashes, make viewpoints.

What you need

  • Autodesk Navisworks Manage or Simulate 2024, 2025 or 2026 on Windows (64-bit). The Clash Detective nodes need Manage.
  • Nothing else: no licence key, no account, no internet connection.

Installing

The Autodesk App Store installer puts Dyncamelo in the Autodesk ApplicationPlugins folder. Close Navisworks first, run the installer, then start Navisworks. No other step is needed.

Your first minutes

  1. Open any model in Navisworks.
  2. On the BIMCamel ribbon tab, in the Visual Programming panel, click Dyncamelo. The editor opens as a dockable pane; dock it, or float it on a second screen.
  3. Open a ready-made graph: File > Sample Graphs in the editor's menu bar lists the built-in ones. Press Run (or switch on Auto) and look at the values shown under the nodes.
  4. Start your own: press Space on the empty canvas, type a word (for example search) and press Enter to drop a node there. Drag from a dot on one node to a dot on another to connect them.
  5. Press F1 for every shortcut, or Ctrl+Shift+P to search every command by name.

The Dyncamelo Player button next to it runs a saved graph from a simple form, without opening the node editor. Hand it to colleagues who only need to press Run.

Good to know

  • Graphs from other people. A graph is a small program. Before Dyncamelo runs a graph from a file that starts programs, uses the network or deletes or overwrites files, it lists those nodes and asks. Run only graphs you trust.
  • Undo. Changes a graph makes to the model go through Navisworks, so Navisworks' own Undo applies. Save the model first when you try a graph you did not write.
  • Where your files are. Your settings are in %APPDATA%\Dyncamelo. Graphs are ordinary .dyc files wherever you save them.
  • Privacy. Dyncamelo collects nothing and sends nothing. The policy is in the app under Help > Privacy Policy.

If something does not work

  1. In the editor choose Help > Run Self-Test. It checks the Navisworks nodes against your Navisworks and your model and puts a report on the clipboard.
  2. Choose Help > Copy Diagnostics and paste the text into your message. It holds versions and the end of the error log, with your user and computer names replaced.
  3. Look in %APPDATA%\Dyncamelo\errors.log.

Known problems and fixes: Troubleshooting. The whole editor is described in the editor guide, and every node in the node catalogue.

Uninstalling

Use Settings > Apps in Windows (or delete the Dyncamelo.bundle folder from the ApplicationPlugins folder) while Navisworks is closed. Your graphs and the folder %APPDATA%\Dyncamelo are left alone; delete that folder too if you want everything gone.
